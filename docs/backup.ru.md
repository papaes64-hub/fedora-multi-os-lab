# Эталонный архив: сначала безопасность

На Fedora выполнить `bash scripts/backup-local-config.sh`. Команда создаёт локальный архив выбранных файлов и `sha256`. **Она не копирует `.qcow2`, `.img`, `.iso`, UEFI, OpenCore-диски, Guest OS userdata, папку обмена или секреты из домашней директории целиком.** Но XML и реальные конфигурации всё равно могут содержать приватные данные, поэтому архив **не публиковать** и хранить с доступом только владельца.

В комплект входят **если существуют**:

- `~/VMs/chromeos-flex-sound-share.sh` — фактически работающий запуск Flex;
- `~/OSX-KVM/OpenCore-Run.sh`, `~/OSX-KVM/OpenCore-Run-Plus.sh` — локальные скрипты Sonoma;
- отдельные созданные ярлыки `~/.local/share/applications/macos-sonoma.desktop`, `chromeos-flex.desktop`;
- `virsh -c qemu:///system dumpxml --inactive win10` — конфигурация Windows 10 (личная);
- минимальные данные о ядре и пакетах (не полный список приложений).

## Что ещё НЕ входит

**Сами виртуальные диски.** Для полной аварийной копии выключить каждую VM и отдельно сохранить диски, UEFI variables и связанные с VM файлы в закрытое хранилище достаточного объёма. Не копировать активные qcow2 простым `cp` или `tar` без snapshot-aware технологии. Архив конфигурации сам по себе не восстановит операционную систему.

Восстановление: сначала установите Fedora/QEMU/libvirt, убедитесь в наличии законных гостевых ОС и файлов VM, сверьте пути и права, проверьте скрипты командой `bash -n`, затем применяйте изменения только на **выключенных** виртуальных машинах. Не перезаписывайте существующий XML или скрипт до сравнения.
