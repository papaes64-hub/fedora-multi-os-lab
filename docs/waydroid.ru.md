# Waydroid на Fedora 44

В ходе работы над «Зоопарком систем» пользователь подтвердил **установку Waydroid** в Fedora 44, но в этой ветке **не подтверждены** его текущие папки, контейнерная конфигурация, звук или графика. Поэтому сценарии автоматической привязки папок из прошлых Linux-дистрибутивов в этой публикации **не объявляются проверенными для Fedora**.

Безопасные проверки на Fedora (только чтение):

```bash
command -v waydroid || true
waydroid status || true
systemctl status waydroid-container --no-pager || true
```

Когда конфигурация будет проверена и будет согласовано, какие сведения можно публиковать, дополним руководство отдельным воспроизводимым разделом.
