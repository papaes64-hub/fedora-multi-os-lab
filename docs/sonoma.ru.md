# macOS Sonoma через OSX-KVM — заметки по проверенной работе

**Оговорка по лицензии:** Apple разрешает использование macOS Sonoma на Apple-branded systems; Intel N95 не соответствует этому условию. Здесь описан исторический эксперимент, без распространения дистрибутива Apple, OpenCore-образов, прошивок и виртуальных дисков. [SLA](https://images.apple.com/legal/sla/docs/macOSSonoma.pdf).

На Fedora 44 использовалась уже установленная Sonoma, перенесённая **копированием** `qcow2` из Quickemu в OSX-KVM. Исходник оставался нетронутым. Виртуальный диск целиком **не публикуется**.

Подтверждённые параметры:

- KVM + QEMU, **16 ГиБ RAM, 3 vCPU**; хост Intel N95 4 ядра.
- `taskset -c 1-3` (оставлено ядро 0 для хоста); профиль CPU `Skylake-Client` со специализированными ограничениями из локального проекта.
- `vmware-svga`; GTK `zoom-to-fit=on,gl=off`. В меню GTK/QEMU «View → Zoom To Fit» и «Fullscreen» изображения показывались почти на весь экран. **Это масштабирование, не автоматическая смена разрешения гостя**.
- `-audiodev pipewire,id=snd0` + `-device virtio-sound-pci,audiodev=snd0` — звук подтверждён.
- `-netdev user,id=net0,smb=/home/USER/Общедоступные` и `virtio-net-pci` — гостевой Finder подключился к `smb://10.0.2.4/qemu` как гость. Папка `sonoma-test` и `.DS_Store` появились на хосте.
- Гостевое разрешение при настройке: **1280×800**.

Реальный рабочий локальный скрипт: `~/OSX-KVM/OpenCore-Run-Plus.sh`. В архив публикации **не включены** `OVMF`, OpenCore-образы, macOS VM-диск или реальный пользовательский скрипт. Команда-обёртка `scripts/launch-sonoma-installed.sh` проверяет наличие вашего рабочего скрипта и запускает его; она **не устанавливает macOS**.

Для воспроизведения на поддерживаемом оборудовании используйте [OSX-KVM](https://github.com/kholia/OSX-KVM) и собственные законно полученные компоненты. Перед экспериментом всегда выключайте гостя и делайте копию диска.
