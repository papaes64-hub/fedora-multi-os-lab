# «Зоопарк систем» на Fedora 44 — руководство

**Проверено 28 октября 2026 года** на Intel N95 (4 физических ядра), 32 ГиБ ОЗУ, SSD 2 ТБ. Основная система — Fedora 44. Это протокол реально подтверждённых настроек, а не обещание, что любое оборудование поведёт себя так же.

## Что работает

| Гость | Запуск | ОЗУ / vCPU | Звук | Экран | Общая папка |
| --- | --- | --- | --- | --- | --- |
| ChromeOS Flex | QEMU/KVM, отдельный скрипт | 12 ГиБ / 4 | PipeWire + Intel HDA — да | VirtIO VGA — да | QEMU SMB, чтение/запись — да |
| Sonoma | OSX-KVM / OpenCore | 16 ГиБ / 3 | PipeWire + VirtIO Sound — да | VMware SVGA, `Zoom To Fit` + Fullscreen — да | QEMU SMB, чтение/запись — да |
| Windows 10 | libvirt, `win10` | ~12 ГиБ / 2 | ICH9/SPICE — да | QXL/SPICE — да | SPICE WebDAV, чтение/запись — да |
| Waydroid | Установлен | — | Не проверяли | Не проверяли | Не проверяли |

Полноценное автоматическое изменение разрешения macOS при растягивании окна **не подтверждено**. Работает именно масштабирование изображения. После перезагрузки Windows сетевой WebDAV-диск появился как **Z:** (раньше Y:); буква может меняться. Передача папки Windows зависит от работающего клиента Virt-Viewer.

> На четырёхъядерном N95 лучше запускать по одной ресурсоёмкой виртуальной машине за раз. Не меняйте конфигурации работающих машин.

## Быстрый старт на Fedora

Проверьте компоненты и пути (без изменений системы):

```bash
bash scripts/verify-host.sh
```

Создайте **личный** архив настроек (без дисков и образов):

```bash
bash scripts/backup-local-config.sh
```

Архив будет создан в `~/Fedora-Multi-OS-Lab-Archives/` с контрольной SHA-256. **Не публикуйте его**: там реальные пути, XML и параметры конкретной установки.

## Публикация / безопасность

- В GitHub отправлять **только** проверенные вручную файлы этого репозитория.
- Никаких `.qcow2`, `.img`, `.iso`, UEFI/OVMF, OpenCore-дисков, ключей, паролей, личных архивов, токенов, приватных XML.
- Учтите ограничения лицензий на гостевые системы. [Лицензия macOS Sonoma](https://images.apple.com/legal/sla/docs/macOSSonoma.pdf) предусматривает использование на компьютерах Apple; Intel N95 — эксперимент вне этих условий. Образы macOS не распространяются.
- Для воспроизведения нужны собственные законно полученные ОС и программы.
